# Code of Conduct

Be respectful, specific, and constructive. Discuss ideas and evidence without
attacking people. Do not harass, threaten, discriminate, expose private
information, or use the project to promote spam, deception, or unsafe search
practices.

Maintainers may edit or remove content and restrict participation when behavior
puts contributors, users, websites, or third-party services at risk. Report a
conduct concern privately through the maintainer's GitHub profile rather than
posting sensitive details in a public issue.
