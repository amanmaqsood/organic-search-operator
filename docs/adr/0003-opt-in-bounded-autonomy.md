# Use opt-in bounded autonomy with daily recent intelligence

The public default remains review-first, while a project may explicitly select
`autonomous_safe` to authorize one reversible work item per daily cycle without
per-run founder approval. Every scheduled cycle consults a recent intelligence
brief from the separately installed Last 30 Days skill, reusing it for at most
24 hours; recent discussion strengthens but never replaces Search Console,
site, conversion, and source evidence. Autonomous publication requires a clean
worktree, a declared deployment route, green checks, a non-sensitive topic,
live verification, and a working rollback path. This trades maximum speed for a
small mutation envelope that limits blast radius and keeps review-first behavior
unchanged for existing installations.
