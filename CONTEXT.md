# Organic Search Operations

This context defines the language used by the skill to coordinate search growth
without confusing discovery, indexing, ranking, and business outcomes.

## Language

**Primary landing page**:
The designated conversion-focused URL whose qualified organic results the project is trying to improve.
_Avoid_: Money page, target page

**Supporting cluster**:
A set of distinct, internally linked pages that answer adjacent intents and strengthen the primary landing page's topical context.
_Avoid_: Content farm, blog volume

**Opportunity**:
An evidence-backed candidate action with a defined page, expected effect, risk, and measurement plan.
_Avoid_: Keyword idea, SEO hack

**Work item**:
An approved or proposed change that implements one opportunity through a fix, refresh, new page, or experiment.
_Avoid_: Article quota, task content

**Submission**:
A notification or sitemap action that helps a search engine discover a URL but does not guarantee crawling or indexing.
_Avoid_: Indexing request, forced indexing

**Inspection**:
A read of the search engine's reported URL state, canonical choice, crawl information, and index eligibility.
_Avoid_: Index submission

**Run record**:
An append-only account of one automation cycle, including evidence dates, actions, results, blockers, and next candidates.
_Avoid_: Memory summary, status blob

**Experiment ledger**:
A history of practitioner or project hypotheses, their source, expected effect, safeguards, measurement window, and outcome.
_Avoid_: Tips database, growth hacks

**Review-first**:
The operating mode in which the skill may prepare and verify changes but needs approval before publishing or external mutations.
_Avoid_: Fully autonomous, advisory-only
